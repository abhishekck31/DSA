# Recursion Mastery Journal

Welcome to the Recursion Mastery Journal. This repository serves as a structured roadmap for mastering recursion, tracking patterns from the simplest foundations all the way up to complex constraint satisfaction problems. 

## Roadmap: How Patterns Connect

The files are grouped into 10 fundamental patterns. They build on each other. Once you master this roadmap, you will have the necessary mental model for Trees and Graphs, which depend entirely on recursive thinking.

1. **Foundations**: The core "Leap of Faith" concept.
2. **Pick/Not-Pick (Bounded)**: The binary choice model (generating subsequences).
3. **Pick/Not-Pick (Unbounded)**: Allowing reuse of elements.
4. **Loop-based Duplicate Handling**: Skipping duplicates using arrays.
5. **Subsets & Power Sets**: Different terminology, same core pattern as #2 and #4.
6. **Divide and Conquer**: Splitting a problem in half to achieve logarithmic time.
7. **String Building Backtracking**: Building strings character by character.
8. **String Partitioning**: Cutting strings into dynamic chunks.
9. **Grid Backtracking**: Navigating 2D arrays with visited markers.
10. **Constraint Satisfaction**: Hard constraints across matrices and rows.
